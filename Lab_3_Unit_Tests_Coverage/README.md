## 1. Постановка задачи и описание проекта
**Задача 10. Конвертер валют:** написать юнит-тесты и измерить покрытие кода для выданного модуля `main.py`.

Модуль `main.py` предоставляет базовые функции для учёта курсов валют относительно единой базовой единицы и конвертации между ними:
- `set_rate(rates, code, rate_to_base)`: регистрация/обновление курса валюты;
- `convert(rates, amount, from_code, to_code)`: расчёт конвертации суммы;
- `list_currencies(rates)`: получение отсортированного списка валют;
- `has_currency(rates, code)`: проверка наличия валюты в справочнике.

## 2. Установка зависимостей и запуск

### Создание виртуального окружения и установка
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### Запуск тестов
```bash
pytest test_main.py -v
```

### Измерение покрытия кода (Coverage)
```bash
pytest --cov=main --cov-report=term-missing test_main.py
```
