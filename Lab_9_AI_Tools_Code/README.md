- `fsm.py` — конечный автомат управления жизненным циклом стипендиальной заявки (`ScholarshipApplicationFSM`, `ApplicationStatus`, `InvalidStateTransitionError`).
- `test_fsm.py` — юнит-тесты допустимых цепочек, цикла доработки `NEEDS_INFO`, недопустимых переходов и терминальных состояний.
- [docs/ai-review.md](docs/ai-review.md) — подробный отчёт AI-анализа кода (находки ИИ, согласие/несогласие, проверка полноты переходов).
- [docs/prompts.md](docs/prompts.md) — журнал промптов и итераций доработки.

### 3.2. Ключевые промпты
1. *Генерация кода:* «Напиши на Python класс конечного автомата (FSM) для статусов заявки на стипендию (`DRAFT`, `SUBMITTED`, `IN_REVIEW`, `NEEDS_INFO`, `APPROVED`, `REJECTED`). Сделай метод `transit_to` и кастомное исключение при недопустимом переходе».
2. *Генерация тестов:* «Напиши `pytest`-тесты для данного класса FSM. Обязательно проверь терминальные состояния и попытки запрещённых переходов».
3. *Анализ кода (AI-review):* «Проведи code review `fsm.py` и `test_fsm.py`: проверь полноту переходов, краевые случаи, читаемость и возможные проблемы с типизацией или конкурентностью».

Полный журнал итераций доступен в [docs/prompts.md](docs/prompts.md).

### 3.3. Что ИИ сделал хорошо / плохо и что исправлено вручную

### 3.4. Этические и практические риски
- **Утечка данных и секретов:** в промпты не передавались реальные персональные данные студентов, номера студенческих билетов, пароли БД или внутренние регламенты вуза — использовались только обезличенные учебные структуры.
- **«Уверенный» неверный код:** модель без предупреждений сгенерировала бизнес-ошибку (`DRAFT -> APPROVED`), что доказывает необходимость ручного ревью и покрытия тестами всех инвариантов.
- **Галлюцинации и избыточные советы:** во время ревью модель предложила добавить `threading.Lock`, что не решает конкурентность в распределённом веб-сервисе (там нужны транзакции БД); совет был критически оценён и отклонён.
- **Лицензирование и авторство:** сгенерированный шаблон был существенно переработан вручную, без копирования стороннего проприетарного кода.
