## 1. Реализованный модуль
В файле `fsm.py` реализован конечный автомат управления жизненным циклом заявки студента на стипендию с защитой от недопустимых переходов состояний. В файле `test_fsm.py` реализованы тесты корректных цепочек и исключений `InvalidStateTransitionError`.

## 2. Раздел: «Работа с ИИ» (AI Reflection Report)

### 2.1. Использованные инструменты
- **Claude / ChatGPT / Copilot** — генерация начального прототипа FSM, формирование тестов и код-ревью.

### 2.2. Ключевые промпты
1. *Prompt 1 (Генерация кода):* «Напиши на Python класс конечного автомата (FSM) для статусов заявки на стипендию (DRAFT, SUBMITTED, IN_REVIEW, NEEDS_INFO, APPROVED, REJECTED). Сделай метод `transit_to` и кастомное исключение при недопустимом переходе».
2. *Prompt 2 (Автоматизация тестов):* «Напиши pytest-тесты для данного класса FSM. Обязательно проверь терминальные состояния и попытки запрещённых переходов».
3. *Prompt 3 (AI-ревью):* «Проведи code review FSM-класса. Какие краевые случаи, циклические блокировки или проблемы с многопоточностью/типизацией здесь возможны?».

### 2.3. Что предложил ИИ и что было исправлено вручную

| Что предложил ИИ | Проблема / Замечание | Ручное исправление студентом |
|---|---|---|
| ИИ использовал обычные строки (`"DRAFT"`, `"APPROVED"`) в словаре переходов | Риск опечаток в строковых литералах, отсутствие подсказок IDE | Заменено на строгий `Enum(str, Enum)` — `ApplicationStatus` |
| ИИ разрешил прямой переход `DRAFT -> APPROVED` в первой генерации | Грубое нарушение предметной области (стипендия не может одобриться без подачи и проверки деканатом) | Матрица переходов строго переписана: из `DRAFT` возможен переход только в `SUBMITTED` |
| ИИ забыл про статус возврата на доработку документов | Если у студента не читается скан, заявку пришлось бы отклонять насовсем | Добавлено состояние `NEEDS_INFO` с возможностью повторного возврата в `IN_REVIEW` |
| ИИ в тестах проверял только успешный переход | Отсутствовали проверки терминальных состояний | Вручную написан `test_terminal_state_immutable` для проверки неизменяемости `APPROVED` |
