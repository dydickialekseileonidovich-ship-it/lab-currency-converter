## 1. Таблица находок ИИ и ручной оценки

## 2. Проверка полноты матрицы переходов

| Из статуса | Разрешённые переходы | Обоснование предметной области |
|------------|----------------------|--------------------------------|
| `DRAFT` | `SUBMITTED` | Студент завершает заполнение и отправляет заявку |
| `SUBMITTED` | `IN_REVIEW`, `DRAFT` | Деканат берёт в работу или студент отзывает до начала проверки |
| `IN_REVIEW` | `APPROVED`, `REJECTED`, `NEEDS_INFO` | Решение инспектора/комиссии или запрос недостающих справок |
| `NEEDS_INFO` | `IN_REVIEW`, `REJECTED` | Повторная проверка после досылки документов или отказ по дедлайну |
| `APPROVED` | `∅` (терминальный) | Утверждённая заявка передана в бухгалтерию, изменение запрещено |
| `REJECTED` | `∅` (терминальный) | Окончательный отказ (при необходимости студент подаёт новую заявку) |
