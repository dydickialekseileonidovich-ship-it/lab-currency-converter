## Итерация 1: Генерация каркаса FSM
- **Промпт:** «Напиши на Python класс конечного автомата (FSM) для статусов заявки на стипендию (`DRAFT`, `SUBMITTED`, `IN_REVIEW`, `NEEDS_INFO`, `APPROVED`, `REJECTED`). Сделай метод `transit_to` и кастомное исключение при недопустимом переходе.»
- **Результат ИИ:** Получен рабочий прототип с таблицей переходов на словаре строк.
- **Ручная правка:** Перевёл статусы на `ApplicationStatus(str, Enum)`, убрал ошибочный прямой переход `DRAFT -> APPROVED`, добавил отзыв `SUBMITTED -> DRAFT`.

## Итерация 2: Генерация автотестов
- **Промпт:** «Напиши `pytest`-тесты для данного класса FSM. Обязательно проверь терминальные состояния и попытки запрещённых переходов.»
- **Результат ИИ:** Сгенерированы базовые тесты «счастливого пути» и один негативный тест.
- **Ручная правка:** Добавлен отдельный тест `test_cycle_with_needs_info` (возврат на доработку и последующее отклонение) и `test_terminal_state_immutable` (неизменяемость `APPROVED`).

## Итерация 3: AI-assisted code review
- **Промпт:** «Проведи code review `fsm.py` и `test_fsm.py`: проверь полноту переходов, краевые случаи, читаемость и возможные проблемы с типизацией или конкурентностью.»
- **Результат ИИ:** Подсвечены риски неполных переходов, идемпотентности и конкурентного доступа.
- **Ручная правка:** Все находки разобраны и зафиксированы в [ai-review.md](ai-review.md); избыточное предложение про `threading.Lock` отклонено с обоснованием.
