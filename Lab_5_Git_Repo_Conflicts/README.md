## 1. Сценарий работы

В проекте моделируется работа двух отделов студенческой типографии:
1. **Маркетинг (ветка `promo-discount`)** — вводит временные сниженные тарифы на печать и стандартный дипломный переплёт к сессии.
2. **Производство (ветка `new-services`)** — добавляет новые услуги (чертежи А1, пружинная брошюровка) и корректирует базовую сетку цен в тех же самых строках.

## 2. Пошаговые команды Git

```bash
# 1. Инициализация и первый коммит
git init
git checkout -b main
# Создан price.md с базовыми тарифами
git add price.md
git commit -m "feat: начальный прейскурант типографии"

# 2. Создание веток
git branch promo-discount
git branch new-services

# 3. Изменения в ветке скидок
git checkout promo-discount
# Редактирование price.md: снижение цен на ч/б и цвет
git add price.md
git commit -m "promo: скидочные цены к сессии"

# 4. Противоречивые изменения в ветке новых услуг
git checkout new-services
# Редактирование price.md: добавлены чертежи А1 и изменена стоимость в тех же строках
git add price.md
git commit -m "feat: добавление чертежей А1 и пересмотр базовых цен"

# 5. Слияние promo-discount в main
git checkout main
git merge promo-discount   # Fast-forward

# 6. Попытка слияния new-services и получение конфликта
git merge new-services
# Вывод:
# Auto-merging price.md
# CONFLICT (content): Merge conflict in price.md
# Automatic merge failed; fix conflicts and then commit the result.
```

---

## 3. Анализ конфликтных маркеров и разрешение

Фрагмент файла `price.md` в момент конфликта:
```markdown
<<<<<<< HEAD
1. Ч/Б печать А4 (акция для студентов): 0.15 BYN / стр.
2. Цветная печать А4 (акция): 0.60 BYN / стр.
3. Твёрдый переплёт диплома (сезонная скидка): 15.00 BYN / шт.
=======
1. Ч/Б печать А4: 0.25 BYN / стр.
2. Цветная печать А4: 0.90 BYN / стр.
3. Печать чертежей А1: 4.50 BYN / шт.
4. Твёрдый переплёт диплома (с тиснением): 22.00 BYN / шт.
>>>>>>> new-services
```

### Принятое решение
При разрешении конфликта принято бизнес-решение:
- Сохранить **скидочные студенческие цены** на стандартную печать и обычный переплёт из `promo-discount`.
- Интегрировать **новые услуги** (чертежи А1, брошюровка) и вынести переплёт с тиснением отдельной строкой из `new-services`.

```bash
# Фиксация разрешения:
git add price.md
git commit -m "merge: объединение новых услуг с сохранением студенческих промо-скидок"

# Публикация в удалённый репозиторий:
git remote add origin https://github.com/duditskiy/printing-service-price.git
git push -u origin main
```
