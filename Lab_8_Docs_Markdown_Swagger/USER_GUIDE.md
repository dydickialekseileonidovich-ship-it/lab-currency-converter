# Руководство пользователя: Портал подачи стипендиальных заявок

## 1. Для студентов
### Как подать заявку:
1. Войдите в личный кабинет студента.
2. В боковом меню выберите раздел **«Стипендии и льготы» -> «Подать заявку»**.
3. Выберите нужный тип стипендии:
   - *Академическая* (по результатам сессии);
   - *Социальная* (по льготным категориям);
   - *Повышенная за научно-исследовательскую работу*.
4. Проверьте автоматически подставленные личные данные (ФИО, номер студенческого билета).
5. Прикрепите необходимые подтверждающие документы в формате PDF (справки, дипломы олимпиад, сканы статей).
6. Нажмите кнопку **«Отправить на рассмотрение»**. Заявка перейдёт в статус `SUBMITTED`.

### Отслеживание статуса:
- В разделе **«Мои заявки»** отображается актуальный статус:
  - `SUBMITTED`: Заявка зарегистрирована и ожидает очереди на проверку.
  - `IN_REVIEW`: Документы проверяются инспектором деканата.
  - `NEEDS_INFO`: Требуется заменить нечитаемый скан документа или донести справку.
  - `APPROVED`: Заявка одобрена, передана в бухгалтерию для начисления выплат.
  - `REJECTED`: Заявка отклонена (с обязательным указанием причины).

---

## 2. Для сотрудников деканата и стипендиальной комиссии
1. Перейдите во вкладку **«Модерация заявок»**.
2. Используйте фильтр по статусам для выбора необработанных обращений (`SUBMITTED`).
3. Откройте карточку студента, ознакомьтесь с прикреплёнными файлами и академической ведомостью.
4. Выберите действие: **«Одобрить»**, **«Запросить сведения»** или **«Отклонить»**. Заполните комментарий эксперта.
