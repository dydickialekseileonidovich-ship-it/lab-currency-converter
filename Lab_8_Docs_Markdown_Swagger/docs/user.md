# Руководство пользователя: Портал подачи стипендиальных заявок

## 1. Доступ к порталу
- Перейдите на главную страницу портала и авторизуйтесь через единую учётную запись вуза (LDAP / личный кабинет студента или сотрудника).
- После входа роль пользователя (`STUDENT` или `DEANERY_STAFF`) определяется автоматически.

## 2. Для студентов
### Как подать заявку
1. В боковом меню выберите раздел **«Стипендии и льготы» → «Подать заявку»**.
2. Выберите нужный тип стипендии:
   - *Академическая* (`ACADEMIC`) — по результатам экзаменационной сессии;
   - *Социальная* (`SOCIAL`) — для студентов льготных категорий;
   - *Повышенная за научно-исследовательскую работу* (`INCREASED_RESEARCH`);
   - *Повышенная за спортивные достижения* (`INCREASED_SPORT`).
3. Проверьте автоматически подставленные личные данные (ФИО, номер студенческого билета).
4. Прикрепите необходимые подтверждающие документы в формате PDF/JPG/PNG (до 15 МБ).
5. Нажмите кнопку **«Отправить на рассмотрение»**. Заявка перейдёт в статус `SUBMITTED`.

### Отслеживание статуса заявки
В разделе **«Мои заявки»** отображается актуальный статус каждой заявки:
- `DRAFT` — черновик (ещё не отправлен в деканат);
- `SUBMITTED` — заявка зарегистрирована и ожидает очереди на проверку;
- `IN_REVIEW` — документы проверяются инспектором деканата;
- `NEEDS_INFO` — требуется заменить нечитаемый скан или прикрепить недостающую справку;
- `APPROVED` — заявка одобрена и передана в бухгалтерию для начисления выплат;
- `REJECTED` — заявка отклонена (в карточке указана причина в поле комментария).

## 3. Для сотрудников деканата и стипендиальной комиссии
1. Перейдите во вкладку **«Модерация заявок»**.
2. Используйте фильтр по статусу (`SUBMITTED` или `IN_REVIEW`) для выбора необработанных обращений.
3. Откройте карточку заявки, проверьте прикреплённые файлы и академическую ведомость.
4. Выберите действие: **«Одобрить»** (`APPROVED`), **«Запросить сведения»** (`NEEDS_INFO`) или **«Отклонить»** (`REJECTED`), указав комментарий эксперта.

## 4. Частые вопросы и типичные ошибки (FAQ)
- **Ошибка «400 Неверные параметры запроса» при подаче:** проверьте, что заполнены обязательные поля `student_name`, `student_card` и выбран корректный тип стипендии.
- **Нельзя изменить уже отправленную заявку:** редактировать заявку можно в статусе `DRAFT` или после возврата деканатом в статус `NEEDS_INFO`.
- **Заявка не найдена (`404`):** убедитесь в корректности идентификатора заявки и прав доступа (студент видит только собственные заявки).
